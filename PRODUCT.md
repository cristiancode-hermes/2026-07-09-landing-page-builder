# Product

## Register

product

## Platform

web

## Users

marketers and non-developers who need to create and publish landing pages without coding

## Product Purpose

Empower anyone to build beautiful, published landing pages without writing a single line of code

## Brand Personality

creative, visual, empowering

## Anti-references

- Generic SaaS templates with purple-to-blue gradients
- Over-designed dashboards where data is buried in decoration
- AI-generated interfaces that all share one look (Inter font, cream backgrounds, rounded everything)
- Enterprise apps that confuse density with professionalism

## Design Principles

- Drag and drop should feel like direct manipulation, not form filling
- Templates as starting points, not cages
- Live preview means what you see IS what you get
- Revision history means no publish is permanent

## Accessibility & Inclusion

- WCAG 2.1 Level AA compliance target
- Proper color contrast ratios (body text >= 4.5:1, large text >= 3:1)
- Keyboard navigable interface
- Screen reader friendly semantic HTML
- Support for prefers-reduced-motion and prefers-color-scheme
